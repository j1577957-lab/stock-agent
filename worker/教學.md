# 🛠️ Pit Garage 小後台設定教學（Cloudflare Workers，免費）

設定完成後，在指揮站「下達任務」輸入問題，技師就會真的交給 Claude 處理，然後把答案回報在 TEAM RADIO。

```
指揮站網頁 ──任務＋通關密碼──▶ Cloudflare 小後台（保管 API 金鑰）──▶ Claude
          ◀──────────── 技師回報 ────────────────────────────────┘
```

大約 15 分鐘，需要準備：
- 你的 **Claude API 金鑰**（`sk-ant-...`，就是股票 Agent 用的那一把）
- 自己想一組**通關密碼**，例如 `pit2026box`。不要用你其他帳號的密碼。

---

## 第 1 步：註冊 Cloudflare

1. 打開 <https://dash.cloudflare.com/sign-up>
2. 用 Email 註冊，到信箱收驗證信並點連結
3. 如果問你要做什麼（例如加網域），直接跳過或回到首頁就好，**不需要買網域**

## 第 2 步：建立 Worker

1. 左邊選單點 **Workers & Pages**（有時候顯示為 **Compute (Workers)**）
2. 按 **Create**（建立）→ 選 **Create Worker**／**Start with Hello World!**
3. 名字改成 `pit-garage` → 按 **Deploy**（部署）

## 第 3 步：貼上後台程式

1. 部署完成的頁面，按 **Edit code**（編輯程式碼）
2. 另開一個分頁，打開這個網址：
   <https://github.com/j1577957-lab/stock-agent/blob/main/worker/worker.js>
   在程式碼右上角按「**Copy raw file**」（兩個方框的複製圖示）
3. 回到 Cloudflare 的編輯畫面，點進左邊的程式碼區 → 按 `Ctrl + A` 全選 → `Delete` 刪掉 → `Ctrl + V` 貼上
4. 右上角按 **Deploy**（部署）

## 第 4 步：放入金鑰和通關密碼

1. 回到這個 Worker 的頁面 → 上方 **Settings**（設定）
2. 找到 **Variables and Secrets**（變數和密鑰）→ 按 **+ Add**（新增）
3. 新增兩個，**Type 都選 Secret**（密鑰），Name 要一字不差：

| Type | Variable name | Value |
|---|---|---|
| Secret | `ANTHROPIC_API_KEY` | 你的 `sk-ant-...` 金鑰 |
| Secret | `PASSCODE` | 你自己想的通關密碼 |

4. （建議）再新增第三個 Secret：`FINMIND_TOKEN`，值是你的 FinMind API Token。有放的話，策略技師會直接查台股真實數據：股價、三大法人、融資融券、本益比、月營收、財報、股利、新聞。申請方式見專案 README 的「FinMind 台股資料」。
5. 按 **Deploy**（部署）或 **Save**（儲存）

## 第 5 步：拿到後台網址，交給 Claude

1. Worker 頁面上會顯示網址，長得像：`https://pit-garage.你的名字.workers.dev`
2. 點開它，看到 `{"ok":true,"msg":"Pit Garage 後台運作中"}` 就代表成功了
3. **把這個網址貼給 Claude**（網址可以給，金鑰和通關密碼不要給），Claude 會把它接到指揮站

## 第 6 步：試用

1. 打開指揮站，在「下達任務」輸入：`台積電今天表現如何？`
2. 第一次送出時會跳出視窗問**通關密碼**，輸入你在第 4 步設的密碼（同一台裝置只需要輸入一次）
3. 策略技師會亮起「作業中」，大約 10–30 秒後在 TEAM RADIO 回報 🎉

## 各技師能做什麼

| 技師 | 關鍵字 | 能力 |
|---|---|---|
| 策略技師 | 股、台股、美股、ETF… | 用 FinMind 查台股完整數據（法人、融資、財報、營收…），上網查新聞，並參考你的自選股掃描結果 |
| 爬蟲技師 | 爬、網站、新聞、抓 | 上網搜尋、整理資訊 |
| 賽車工程師 | 其他問題 | 一般問答、解釋、規劃 |
| 行程／信件技師 | 行程、信… | ⚠️ 後台還看不到你的 Gmail 與行事曆，會建議你到 Claude App 問 |
| 電商技師 | 蝦皮… | 尚未上線 |

## 費用與安全

- Cloudflare 免費方案每天 10 萬次請求，個人用不完。
- 每次任務會花一點 Claude API 費用（大約 NT$0.3–2，有上網查資料會比較多）。
- 只有你的網站可以呼叫這個後台，而且要通關密碼才能用；金鑰放在 Cloudflare 的保險箱裡，網頁上看不到。
- 通關密碼外流的話：到第 4 步把 `PASSCODE` 改掉，網頁會自動重新詢問密碼。
